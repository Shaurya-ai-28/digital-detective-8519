### Task 1.1 — Trace One Activity Using IPOS
**Activity:** Typing code in an editor and saving it.

| Stage | What happens | Hardware / component |
| :--- | :--- | :--- |
| **Input** | Typing letters on the keyboard. | Laptop keyboard |
| **Processing** | CPU takes keystrokes and keeps text in memory (RAM). | Processor (CPU) and RAM |
| **Output** | Display shows typed characters on screen in real time. | Laptop display screen |
| **Storage** | Saving writes file from temporary RAM onto SSD permanently. | Internal SSD |

**Flow:** Input brings keystrokes in -> Processing stores them in RAM -> Output displays them on screen -> Storage saves them permanently to the SSD.

## 4. My understanding
All computers follow IPOS: take input, process data, show output, and save to storage. Operating systems manage hardware, application software helps users do tasks, and utility software maintains the system.

## 5. Difficulties faced
Remembering the difference between RAM and SSD storage.

## 6. How I resolved them
RAM is fast and temporary (cleared when turned off); SSD is permanent storage where files remain saved.
